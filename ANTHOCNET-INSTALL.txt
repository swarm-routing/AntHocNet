AntHocNet 2.9.0 — drop-in ns-3 modules

  tar -xzf anthocnet-ns3-modules-2.9.0.tar.gz -C /path/to/ns-3/contrib
  cd /path/to/ns-3
  ./ns3 configure --enable-examples --enable-tests && ./ns3 build
  ./test.py -s anthocnet && ./ns3 run anthocnet-example

Contents: contrib/anthocnet (the module + harnesses; it carries the algorithm
core/), contrib/swarm-core (the module it links, at the release
swarm-adapter-ns3.lock names, swarm-routing/swarm-adapter-ns3 v2.0.0 73f8f0de8417c05f97ae9903953e0825202c1f58) and the comparison
modules contrib/aomdv, contrib/gpsr, contrib/oracle, contrib/adaptive and the harness
module contrib/routing-bench (swarm-routing/sim-tools v1.1.4 9b0908d0734b5a235f7d31c6051594d767801de3, from
ns3-tools.lock). Delete those five to
build AntHocNet alone; ns-3 then skips the comparison harnesses.
Tested on ns-3.36 to ns-3.48. Docs: https://swarm-routing.github.io/AntHocNet/docs/
